# folium-mod-music-party

Music Party for Folia · [插件仓库](https://github.com/tabidachinokaze/folium-mod-music-party) · [适配版 Folia](https://github.com/tabidachinokaze/folia-major)

与网易云官方 **多人一起听** 房间互通的 Folium 插件。好友继续使用网易云官方手机 App；Folia 负责音乐播放、歌词和视觉效果。

## 安装

1. 安装 [Folia 0.7.20](https://github.com/tabidachinokaze/folia-major/releases/tag/v0.7.20)。也可从主分支源码运行：

   ```bash
   git clone git@github.com:tabidachinokaze/folia-major.git
   cd folia-major
   npm ci
   npm run dev:electron
   ```

2. 下载 [插件 0.3.19 ZIP](https://github.com/tabidachinokaze/folium-mod-music-party/releases/tag/v0.3.19)。也可从主分支构建：

   ```bash
   git clone git@github.com:tabidachinokaze/folium-mod-music-party.git
   cd folium-mod-music-party
   npm ci
   npm run build
   ```

3. 在 Folia 的「设置 → 实验室」开启模组系统，将 `folium-mod-music-party-0.3.19.zip` 拖入模组面板并启用。在 Folia 登录网易云后，点击播放栏的一起听图标或执行「打开网易云多人一起听」。
4. 登录网易云且当前音乐来源为网易云时，私信和一起听入口自动显示，无需手动连接。恢复检测到的房间、粘贴官方邀请链接，或播放网易云歌曲后创建房间。私信可以直接从首页顶部胶囊进入，无需先加入房间。

Folia 0.7.11 已包含宿主接口，无需打补丁。若从本 fork 的 0.7.10 源码（基线 `76e1dfe`）适配，可执行 `node scripts/apply-host-patch.mjs /path/to/folia-major`，再重新构建桌面版。补丁不能修改已安装应用的 ASAR，也不适用于上游原版 0.7.9。

运行时使用 Folia 自带的本地网易云 API，不需要 Docker 或独立 Music Party 客户端。插件不会另存 Cookie；账号和音乐来源切换时会自动更新入口并释放本地同步。协议代码随仓库提供，构建不依赖旁边的源码目录。

## 0.3.1：私信界面优化

私信采用固定高度双栏布局：会话显示头像、用户名和最新消息预览；列表底部自动加载会话，消息上方滚动加载历史并保留阅读位置。私信反馈与房间状态隔离，图片等附件不再重复显示占位文字。

输入区提供 Emoji、颜文字、表情包和图片浮层。支持私信图片上传，以及网易云自定义表情上传、整理、多选删除；删除以官方 `data.result` 确认为准。表情收藏不会发送给好友。测试仅使用模拟接口，没有发送真实私信。

完整的无外层滚动布局需同时升级 Folia 0.7.12；此版本已包含首页容器高度修复。

## 0.3.2：房间与成员

房间 tab 只显示房间概况、邀请和退出操作。成员 tab 显示在线成员的头像、昵称与推荐数，点击后查看该成员的已播、待播记录及当前歌曲；已播显示点赞数，待播可置顶，本人推荐可删除。统计来自完整分页的已播记录与待播队列，按房间歌曲条目 ID 去重，不将系统推荐归到成员名下。在线成员资料以状态接口实际返回为准；推荐数统计当前接口仍保留的记录，不包含已删除的推荐。接口失败时显示错误，不用零冒充未知数量。

## 0.3.4：原生侧栏风格与自动启用

统一房间、成员、聊天、私信和弹窗的字号、圆角、间距、图标与明暗主题；去掉插件根容器的重复内边距、大品牌头图及固定配色。房间恢复、创建/匹配、链接加入分成独立卡片；邀请与退出位于房间页底部。成员页使用图标操作，不再单独显示正在播放区块。

登录网易云且当前使用网易云时自动启用入口。进入面板只检查账号当前房间，点击恢复后才接管播放；未加入房间时不显示成员/聊天标签。

创建房间新增“允许陌生人匹配”开关，并提供匹配、取消及退出当前房间后重新匹配入口。0.3.5 首次接入通知但存在生产应用标识与传输不兼容问题，已在 0.3.6 修复并通过真实账号匹配入房验证。

## 0.3.5：匹配、连续播放与聊天

配套 Folia 0.7.13。操作结果与错误使用宿主 toast；匹配先连接官方轻量通知服务，收到待确认房间后调用确认接口入房，支持失败通知、独立超时和取消。匹配等待期间保持普通播放，重新匹配及主动退出房间保留当前歌曲与进度。

聊天打开定位最新，向上滚动加载历史并保留阅读位置。文本和表情为主要消息，推荐/点赞/进出等房间动态使用低对比文字行，不显示常驻说明和更早消息按钮。

## 0.3.6：真实账号匹配修复

修正生产通知应用标识，并将匹配通知连接放入插件主进程，使用官方音乐专用 mini 通道。普通 Web IM SDK 虽能认证，但无法收到该业务的房间匹配通知，因此已移除该依赖。认证凭据只在主进程内存中使用，不通过匹配 RPC 返回前端或写入插件存储。

通知帧有大小限制、压缩校验、去重和回执，只传递多人匹配结果。取消、账号切换、插件停用及页面失联会关闭连接；服务端匹配期限后保留短暂通知传输余量，确认入房使用独立超时。等待匹配时保持当前播放。

已使用授权真实账号完成通知连接、匹配、确认入房及退出清理，全程没有发送聊天或推荐歌曲。自动化测试继续使用本地模拟服务。

## 0.3.8：聊天工具与匹配选歌

房间动态用小图标区分加入、推荐、点赞等类型，并区分昵称、动作和歌曲，保持比文字聊天更低的视觉强调。

房间输入区提供 @、Emoji、颜文字、官方表情包与图片上传。输入 `@` 可搜索成员，点击消息昵称可快速提及；按官方格式发送 `@昵称` 文本，收到完整昵称匹配的提及时在本地高亮。聊天历史向上滚动加载，表情包列表向下滚动加载，均无“加载更多”按钮。

匹配卡片可通过宿主 Omni 搜索并选择网易云歌曲，也可恢复使用当前歌曲；选择只影响下一次匹配，不改变当前播放或向房间推歌。待播队列的置顶按钮旁、成员推荐列表显示接口返回的被置顶次数；未返回统计时不以零代替。

## 0.3.9：侧栏弹窗、聊天布局与英文支持

选歌、Emoji、颜文字、表情包及图片弹窗优先显示在侧栏左侧；空间不足时自动调整位置，切换页面和关闭侧栏时同步关闭。普通聊天显示头像，长昵称、歌曲及连续文本自动换行；修复 UP 动态重复昵称。

成员列表顶部显示当前歌曲推荐者和播放状态动画；当前歌曲归入推荐者的已播列表。已播只显示点赞数，待播置顶次数位于按钮左侧，官方 `songInfo.uped` 状态用于高亮自己置顶过的歌曲。配套 Folia 0.7.14 后，一起听页签改为双人图标。

私信采用头像与内容分列、发送与接收左右对齐的紧凑消息卡片，邀请整合为单张卡片。房间聊天、动态和私信统一显示消息时间：今天仅显示时分，历史消息显示日期，跨年消息包含年份。

插件界面跟随 Folia 的语言设置，提供简体中文和英文，覆盖房间、成员、聊天、私信、弹窗、操作提示及常见错误。昵称、歌曲名和消息原文保持原样。切换语言不退出房间或中断播放。

## 0.3.10：侧栏细节与私信音乐卡片

一起听入口改为双人声波图形，侧栏与播放栏一致（完整图形需 Folia 0.7.15 或更新版本）。长歌名不再撑宽重新匹配卡片；房间聊天使用紧凑工具图标，发送保持同排，输入框提示通过 `@` 提及成员。

成员待播歌曲的置顶次数位于按钮内图标右侧，已置顶状态仍跟随主题色。补全“浅赞一下”动态的昵称去重与点赞分类。私信的单曲、专辑分享将正文、封面、类型、标题与歌手整合为一条音乐卡片，保留消息时间与头像，兼容中英文。

## 聊天显示（开发中，尚未发布）

聊天标签提供「聊天显示」和「弹幕」两个导航入口，分别打开设置弹窗；弹幕开关可直接在导航行操作。「聊天显示」可选择面板内或播放器左下角显示。左下角聊天跟随宿主底部控件显隐，输入和操作弹窗时保持可见；隐藏期间的新消息临时显示，默认 5 秒，可调整为 1–30 秒。浮窗避让左下角正在播放卡片，工具弹窗优先向右展开。

左下角采用直播消息流样式，单行消息为胶囊气泡，多行和图片消息保留大圆角。昵称与正文同行，主消息昵称跟随主题色，图片/表情紧凑展示，房间动态使用较小字号但保持正文对比度。列表根据播放器可用空间展开，保留外边距和控件避让，隐藏滚动条但仍可滚动读取历史。消息不透明度、气泡背景不透明度（默认 35%，可设为完全透明）、输入背景不透明度、字号和行距可独立调整。输入区默认收为「说点什么…」，点击展开完整编辑器；点击外部保留草稿，发送成功后收起。Enter 换行，Ctrl+Enter 发送。设置和表情分组使用宿主风格的下拉菜单，支持键盘选择及逐层关闭；设置弹窗保留宿主侧栏相同的上下安全边距。

弹幕使用 [Danmaku](https://github.com/weizhenye/Danmaku) 网页引擎（MIT），仅展示新到达的房间消息；加载历史或切换歌曲不重复播放。支持滚动、顶部固定、底部固定，显示区域、透明度、字号、速度、字体、粗体和描边/阴影设置，以及文字、图片表情、房间动态过滤、防重叠与重复内容合并。鼠标悬停时只暂停该条弹幕，其他弹幕继续滚动；背景采用胶囊圆角，悬停背景不透明度可在高级设置调整（0–100%，默认 35%）。该网页引擎不是 B 站官方 Android 引擎 DanmakuFlameMaster。

打开弹幕设置时，播放器持续循环显示标有「预览」的本地示例，调整外观和速度时保留当前位置及悬停暂停状态，关闭设置后清除。预览包含文字、图片和房间动态，遵循内容过滤；即使未启用弹幕也可以预览，不发送到房间、不写入聊天记录。

位置、弹幕设置与提示时长保存到宿主模组设置；恢复弹幕默认设置保留启用开关和聊天位置。本地开发版新增 `ui.stage` 权限，用于宿主管理的播放器覆盖层。

## 已实现

- 官方多人房间创建、链接加入、恢复、退出，成员与同步状态。
- 房间歌曲经 Omni 查询并进入 Folia 的正常音频和歌词管线；按服务器时间对齐进度。
- 一起听时，“播放”在本机试听，“加入队列”才向房间推歌；试听结束或主动返回时对齐房间最新进度。房间完整队列接管原生播放列表、命令面板搜索和队列拼贴；移除插件内重复的待播页。
- 房间队列以同步按钮替代打乱，隐藏下一首播放/移到队尾。待播条目支持置顶、删除自己的推荐；只有当前播放条目显示点赞，可连续多次点赞。重复歌曲按官方推荐条目 ID 区分。
- 跟随房间时，原播放栏、拼贴、「下一首」命令和 Ctrl/Cmd+右方向键均发起官方切歌请求。试听时上一首、下一首返回房间；自然结束只查询服务端下一条歌曲，不发送切歌操作。
- 本机暂停跨远端切歌保持暂停，恢复时重新对齐；一起听期间暂停本地循环和混音，退出/禁用后恢复个人队列及原有循环、混音设置。
- 房间文字聊天、@ 成员、Emoji、颜文字、图片上传，以及图片/音视频等历史消息展示、官方自定义表情读取与发送。
- 首页顶部胶囊提供私信入口；会话与分页历史、文字发送、表情发送、官方邀请卡片解析与加入、向所选会话发送一起听邀请。私信只在会话可见且窗口获焦时标为已读。
- 播放栏入口、命令入口、独立房间面板、过渡动画、减少动态效果偏好、点击表情浮层外关闭。

用户在界面点击发送/邀请时才发送消息。停用插件只停止本地同步、释放播放控制，不自动退出服务端房间；需要退出时点击「退出房间」。主动退出时恢复个人队列并保留当前歌曲、进度及播放/暂停状态；当前歌曲不在原队列时插入队首。停用插件仍按宿主默认策略释放播放。

## 当前边界

- 仅桌面 Folium 主窗口；不支持 Web/PWA，也不在私人 FM、Stage、视频录制或混音过渡期间接管。当前官方 API 的版权、会员和风控限制仍然适用。
- 同步及收信使用心跳/状态/历史查询；已加入歌曲结束附近的快速状态重查，房间歌曲和聊天尚未接入实时推送；多人匹配已接入官方云信轻量通知并确认入房。
- 房间和私信图片发送、自定义表情读取/发送/上传/删除已实现。私信文件上传、录音和视频发送尚未移植到插件版；独立客户端中的这些功能继续保留。
- 本版不覆盖所有 Folia 外部播放模式；使用一起听时请通过正常网易云歌曲入口选歌。插件没有自定义完整音源 provider。
- 插件更新使用相同 ID 的新 ZIP 安装；由于 Folium 的信任确认绑定文件内容，更新后需要重新启用。尚无插件自身的自动更新器。

## 开发与验证

在本仓库根目录执行（Node.js 24+）：

```bash
npm ci
npm run check
npm run test:ui
```

首次运行浏览器测试需要 `npx playwright install chromium`。若已有适配后的 Folia Vite 开发服务器，可运行 `FOLIA_URL=http://127.0.0.1:4175 npm run test:ui`，额外验证实际 Folium 注册、音频/歌词加载、原生下一首和循环设置恢复。

`build` 将 `vendor/music-party/src` 中的多人协议、校验、队列和消息解析一起打进插件，产物不依赖源码目录。来源提交及文件指纹见 `vendor/music-party/provenance.json` 和 [NOTICES.md](NOTICES.md)。`src/main` 只允许固定房间/消息操作；普通歌曲搜索与播放走宿主 Omni。`src/client/host.ts` 集中封装 Folia 账号与内部接口适配。

`host-patch/folia-0.7.10.patch` 将 experimental playback.sessions 升级到 v2，增加原生队列投影、条目操作、同步和独立下一首可用状态，并提供通用首页模组入口。租约释放及切换时失效的异步请求不能重新启动歌曲；未启用插件时保持原有路径。

自动化验证使用本地模拟网易云服务，不发送真实私信或房间消息。真实账号跨端联调需使用安装后的适配版 Folia 验收，不能用模拟测试替代。

## 发布与更新

Folia 本体从 [fork 的 GitHub Releases](https://github.com/tabidachinokaze/folia-major/releases) 更新。首次需要安装 fork 构建的应用，后续发布更高版本的正式 Release 和完整更新元数据后，应用内即可检查更新。详细通道说明见 [宿主文档](https://github.com/tabidachinokaze/folia-major/blob/main/docs/desktop/music-party-fork.md)。

本插件推送代码后由 GitHub Actions 检查并上传构建 artifact。准备发布时同步更新 `package.json`、`mod.json`、`RELEASE.md`，再推送对应 `v*` 标签，工作流会发布 ZIP 和 SHA-256 校验值到本仓库 Releases。插件更新仍通过安装新的 ZIP 完成；模组 ID 保持 `music-party`，保留与既有安装的身份一致性。

## 播放接口迁移

- 获取会话改为 `acquire({ onIntent, restore: 'queue-stopped' })`；播放、批量入队、自然结束、播放错误和 seek 使用不同的事件类型。
- `play()` 明确返回音源提交、取消、被替代、不可用或失败；插件只在音源提交并取得 metadata 后对齐进度并播放，取消不再进入 20 秒等待。
- 会话由宿主管理清理，插件也会主动释放。私人 FM、Stage、视频录制和混音过渡中不获取会话，给出可操作的提示；默认释放恢复原队列并停止播放；0.3.5 的主动退出使用新增 `handoff()` 保留当前播放。
- 聊天/私信/房间协议继续留在插件。网易云来源校验也留在插件；宿主接口支持其他 Omni provider。

- v2 新增 `session.setQueue` 与 `session.stop`；队列展示与音频缓存身份分离，点赞/心跳不会重建拼贴。`queue-action` 的权限和官方协议仍由插件处理。
- 私信使用 `registries.homeTabs` / `ui.openHomeTab`；原生队列使用 `ui.openQueue`。停用插件会自动清除首页入口和房间队列。

## 0.3.11：私信资源卡片与点击跳转

活动、会员和歌手推广消息统一为正文、封面与资源信息卡片。歌曲点击后普通播放，在多人房间中则推荐到待播队列；专辑打开 Folia 原生专辑页（需要 Folia 0.7.17）。活动通过官方网页或限定的网易云原生入口打开，原生入口需要设备上有可处理该链接的网易云应用。预约卡片保留预约入口，不当成可播放歌曲。

## 0.3.12：试听、推歌与遥控房间

配套 Folia 0.7.18。一起听时，“播放”只在本机试听，“加入队列”才推荐给房间。私信歌曲在房间内提供试听与推歌选择，取消后不操作；房间外直接播放。试听期间房间继续运行，试听结束或主动返回后对齐最新房间进度。

遥控窗口新增独立的房间点赞和返回房间按钮，下一首按房间状态启用。房间赞可连续点击，红心仍用于收藏当前歌曲；试听允许调整进度。迟到的点赞请求不会转移到另一房间或新的歌曲条目。

“继续一起听”卡片可以直接退出检测到的房间，无需先恢复本地播放接管，成功后清除卡片，失败时保留并提示原因，普通音乐继续播放。宿主同时修复真实网易云专辑数据导致原生专辑页无法打开的问题，返回私信时保持播放不变。

## 0.3.13：表情收藏、图片预览与停止试听

配套 Folia 0.7.19。收到的表情不再重复显示升级 App 的占位提示，右键可添加到自己的网易云表情包；收藏后重新打开表情列表会刷新。房间和私信均可 Ctrl+V 粘贴图片，选择图片和粘贴图片都先预览，再确认发送。取消、关闭弹窗或切换聊天会清理待发送图片。

表情包弹窗随分页内容增高，最多占满侧边面板的可见高度，更多内容在弹窗内部滚动。主播放键、拼贴、独立遥控和系统媒体暂停在试听时改为停止试听，停止后回到最新房间进度并保留房间原来的播放/暂停状态。播放列表不再显示“返回房间”按钮；命令面板和固定命令入口统一显示一起听图标。

## 0.3.14：官方表情收藏协议

右键收藏收到的表情使用网易云官方 `social/emoji/collect`，携带原消息的 `emojiId` 与 `emojiGroupId`；只有服务端 `data.result` 为 true 才确认成功。不会重新上传或发送表情，也不再依赖图片 URL 中的数字图片 ID。上传自己的图片到表情包继续使用独立的上传流程。

## 0.3.15：匹配恢复与聊天交互

重新匹配先正常退出旧房间，确认退出后使用操作开始时选定的匹配歌曲。接管房间播放前固定默认匹配歌曲，避免房间切歌改变下一次匹配依据。发现账号已有房间、服务端换房或本地播放接管失败时保留“继续一起听”卡片；回到窗口或恢复网络时重新检查大厅的房间状态。

修复首次打开聊天出现的空菜单横条。聊天记录按侧栏剩余高度伸缩，输入区保持可见，记录内部滚动。右键收藏菜单贴近所选表情，并用小箭头指向图片。表情包选择弹窗可扩展至整个播放器可见高度，超出部分内部滚动，不再受侧栏高度限制。

房间聊天与私信均支持 Ctrl+Enter 发送；Enter 保持换行，输入法组字期间不会误发送。

## 0.3.16：房间红心、紧凑聊天与图片收藏

配套 Folia 0.7.20。跟随房间播放时，在播放器、侧栏或独立遥控窗口点击红心，个人收藏成功后会为当前歌曲发送官方房间红心事件，由服务端生成互动动态。取消收藏、试听和普通播放不发送房间红心；可重复的房间点赞仍保留独立入口。若房间或歌曲已变化，不把迟到的收藏结果发送到新的房间条目。

空聊天和少量消息按内容收缩，消息增加后才扩展到侧栏可用高度。表情库仍可高于当前较短的侧栏，但保持原生侧栏最大展开区域的上下留白。收藏菜单根据聊天列表可见空间选择图片上方或下方，图片滚出列表后关闭菜单。

自己和他人发送的聊天图片均可添加到表情包：官方表情使用收藏接口，普通图片使用自定义表情上传流程；头像、音乐封面和不受支持的图片地址不提供收藏操作。当前账号已确认收藏过的内容显示“已添加”，取消收藏后可重新添加。

插件目前没有自动检查或安装更新的功能。仍需下载新版 ZIP，在 Folia 模组页安装并重新启用；Folia 本体更新不会自动更新插件。

## 0.3.17：收藏菜单、房间信息与创建用歌

修复 Folia 固定定位布局下，页面根元素高度为零使收藏菜单打开后立即关闭的问题。自己发送的图片及自己或他人的表情包均可正常打开收藏菜单。聊天轮询和新消息保留已有图片节点，避免已打开的菜单突然消失或图片重新加载。

房间信息卡片展示服务端的房间类型和 `roomBizType` 原始值：私密好友房（1）不允许陌生人匹配，公开好友房（2）和公开匹配房（3）允许；未提供或无法识别的类型显示未知，保留原始值，不根据本地创建开关推测。

“开启一场一起听”卡片的“创建”按钮使用选定的匹配用歌曲，在点击时固定本次创建的歌曲。已选歌曲时不再依赖当前正在播放的音乐，选歌弹窗也明确用于创建或匹配房间。

继续配套 Folia 0.7.20；已安装该宿主版本的用户只需更新插件 ZIP 并重新启用。真实账号仅用于读取房间状态及消息结构，自动化测试使用脱敏数据和模拟收藏接口，没有上传图片、发送消息或修改房间。

## 0.3.18：图片收藏格式兼容

收藏聊天图片时，根据图片内容识别 PNG、JPEG、GIF 或 WebP，再使用正确的文件类型上传。修复网易云 CDN 把 PNG 标记成 `image/jpg` 导致格式误报的问题，同时兼容通用二进制或缺失类型的响应；无效图片、下载失败及超限数据仍会被拒绝。

房间信息只显示“私密好友房”“公开好友房”“公开匹配房”等类型名称，移除技术字段括号和重复的匹配权限行。创建房间的“允许陌生人匹配”开关保持原有功能。

继续配套 Folia 0.7.20。使用授权账号只读检查当前房间，对同一张图片复现旧错误并验证修复。另以合成 PNG、JPEG、GIF、WebP 实测完整上传：NOS 存储类型正确，音乐 CDN 对四种格式均返回 `image/jpg`；PNG/WebP 字节不变，JPEG/GIF 有内容处理但保持原格式。上传流程无须修改，收藏时按内容识别 CDN 返回的实际图片格式。测试未发送房间聊天或改动表情库。

## 0.3.19：表情库固定标题

表情库将标题、上传、整理及分组控件保留在顶部，只让下方表情网格滚动，修复原先标题随滚动向上移动的问题。房间聊天和私信共用这套布局，滚动加载更多和播放器高度范围内的展开行为保留。

本版包含 0.3.18 的图片收藏格式兼容与房间信息简化，继续配套 Folia 0.7.20。
